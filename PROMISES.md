# Матрёшка Promise: как объяснить на примере бота

## 1. Что такое Promise

Promise - это «обещание» результата, который появится позже (например, ответ сервера).
У него три состояния:

| Состояние   | Значит               |
| ----------- | -------------------- |
| `pending`   | ещё ждём             |
| `fulfilled` | успех, есть значение |
| `rejected`  | ошибка, есть причина |

Из `pending` Promise переходит в одно из двух других состояний **один раз** и больше не меняется.

## 2. Все методы Promise и где они в боте

### Как создать

| Метод                   | Что делает                                     | Где в боте                              | Как проверить в Telegram |
| ----------------------- | ---------------------------------------------- | --------------------------------------- | ------------------------ |
| `new Promise`           | Promise вручную: `resolve` / `reject`          | `adviceFor` (service.ts)                | `матрёшка`               |
| `Promise.resolve`       | готовый успешный                               | `findCity`: город уже известен (api.ts) | `Алматы`                 |
| `Promise.reject`        | готовый с ошибкой                              | `fetchJson`: сервер вернул 404/500      | только в тестах          |
| `Promise.withResolvers` | Promise и «пульты» `resolve`/`reject` отдельно | `withTimeout`: будильник на 5 секунд    | только в тестах          |
| `Promise.try`           | запускает функцию, всегда даёт Promise         | `answerFor` (service.ts)                | любое сообщение          |

### Как объединить несколько

| Метод                | Кого ждёт                  | Когда ошибка        | Где в боте                       | Как проверить      |
| -------------------- | -------------------------- | ------------------- | -------------------------------- | ------------------ |
| `Promise.all`        | всех                       | если упал хоть один | `compareText`: сравнение городов | `Алматы vs Астана` |
| `Promise.allSettled` | всех                       | никогда             | `allText`, гонка                 | `всё Астана`       |
| `Promise.race`       | первого (успех или ошибка) | если первый упал    | `withTimeout`                    | любой запрос       |
| `Promise.any`        | первого **успешного**      | если упали все      | `getRates`, победитель гонки     | `курс`, `гонка`    |

Разница `race` и `any`: `race` принимает любой первый финиш, даже ошибку, а `any` ошибки пропускает и ждёт успех.

### Как получить результат

| Запись            | Когда выполняется        | Где в боте                    |
| ----------------- | ------------------------ | ----------------------------- |
| `.then`           | при успехе               | `matryoshkaText`, `fetchJson` |
| `.catch`          | при ошибке               | `answerFor`                   |
| `.finally`        | всегда                   | `withTimeout`                 |
| `async` / `await` | то же, но читается проще | `weatherText`, `raceText`     |

## 3. Матрёшка

Запрос погоды по названию - это три шага, и каждому нужен результат предыдущего:

```
findCity("Астана")                ← большая кукла: координаты
  └─ getForecast(place)           ← средняя: погода по координатам
       └─ adviceFor(forecast)     ← маленькая: совет по температуре
```

### Вариант «матрёшка» (в боте)

```ts
return findCity(city).then((place) =>
	getForecast(place).then((forecast) =>
		adviceFor(forecast).then((advice) => `${place.name}: ${advice}`),
	),
);
```

Внутренние функции видят все внешние переменные (`place`, `forecast`), но с каждым шагом код уезжает вправо.

### Вариант «плоская цепочка»

```ts
return findCity(city)
	.then((place) => getForecast(place))
	.then((forecast) => adviceFor(forecast));
```

Короче, но в конце `place` уже не виден.

### Вариант `async` / `await`

```ts
const place = await findCity(city);
const forecast = await getForecast(place);
const advice = await adviceFor(forecast);
return `${place.name}: ${advice}`;
```

Все три делают одно и то же. `await` - это удобная запись для `.then`.

### Главное правило матрёшки

Если внутри `.then` вернуть Promise, внешняя цепочка **сама дождётся его** и передаст дальше уже значение.
Поэтому результат никогда не бывает `Promise<Promise<...>>`: куклы раскрываются до конца.

### Ошибки

Ошибка на любом уровне «проваливается» вниз до первого `.catch`, следующие `.then` пропускаются.
Если `findCity` не нашёл город, погода и совет даже не запрашиваются.

## 4. Вопросы, которые могут задать

**Почему в гонке и сравнении запросы идут одновременно?**
`cities.map(...)` сразу запускает все запросы, а `Promise.all` / `any` только ждут их.

**Чем плохо писать два `await` подряд?**
Второй запрос начнётся после первого, и время сложится. Это нужно, только когда второму нужен результат первого.

**Отменяет ли `Promise.race` медленный запрос?**
Нет. Мы просто перестаём его ждать.
